# Plant Checker

![App Logo](Icon/ic_launcher.png)

**Plant Checker** — приложение для отслеживания и ухода за вашими комнатными растениями. Никогда не забывайте, когда поливать растения!

## Выполненные требования проекта

### Архитектурные решения

- **Clean Architecture с модуляризацией**

  - Модули: `app`, `domain`, `data` и `core`
  - Четкое разделение слоев: представление (UI), предметная область и данные
  - Использование паттерна Repository
  - Использование Use Cases для бизнес-логики

- **Dependency Injection с Koin**
  - Модули для внедрения зависимостей: `appModule`, `useCaseModule`, `viewModelModule`
  - Внедрение репозиториев, ViewModel и Use Cases

### Работа с базой данных и сетью

- **Offline режим с использованием Room**

  - База данных `PlantDatabase` для хранения данных о растениях и событиях полива
  - DAO для работы с данными: `PlantDao`, `CareEventDao`, `ReminderDao`
  - Сохранение растений, их параметров и истории полива

- **Конфигурация OkHttp с перехватчиками**
  - Настроенные перехватчики для логирования, кеширования и добавления API-ключей
  - Работа с API для получения данных о растениях
  - Обработка сетевых запросов и кеширование данных

### UI и навигация

- **Jetpack Navigation**
- Navigation Graph для навигации между фрагментами
- Safe Args для передачи параметров между экранами
- Bottom Navigation для основных разделов приложения

- **Intent и Deep Links**

  - Deep Links для открытия основных экранов:
    - `plantchecker://home` — главный экран
    - `plantchecker://add` — добавление растения
    - `plantchecker://plant/{id}` — детали растения
    - `plantchecker://calendar` — календарь полива
    - `plantchecker://add/{species}` — добавление растения с предзаполненным видом

- **Экраны с Jetpack Compose**
  - `CalendarScreen` — календарь поливов реализован полностью на Compose
  - Использование Material 3 для дизайна компонентов

### Фоновые процессы

- **WorkManager и BroadcastReceiver**
  - WorkManager для планирования уведомлений о поливе
  - BroadcastReceiver для восстановления напоминаний после перезагрузки
  - Периодические напоминания о необходимости полива растений

### Интеграции

- **Firebase**
- Firebase Auth для авторизации пользователей
- Firebase Firestore для синхронизации данных (опционально)
- Firebase Storage для хранения фотографий растений

- **Собственная библиотека**
  - Использование собственной библиотеки для авторизации через Firebase
  - Опубликована в частном репозитории и интегрирована в проект

## Тестирование

## Основные функции

- **Отслеживание растений**: добавление, редактирование и удаление растений с подробной информацией
- **Напоминания о поливе**: уведомления о необходимости полить растения
- **Избранные**: возможность отметить важные растения
- **Календарь**: визуальное отображение расписания полива
- **Журнал ухода**: отслеживание истории полива и других действий
- **Фильтры**: показ всех растений, избранных или требующих полива
